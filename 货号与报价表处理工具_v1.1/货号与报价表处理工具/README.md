# 货号与报价表批量处理工具 v1.1

一条流水线，**纯算法** —— 不联网、不调用任何 AI 模型，100+ 张图也就一分钟。

| 页签 | 做什么 |
|---|---|
| **① 图片文件** | 改写/擦除产品图底部印的货号，并可同时把文件改名（`JT666-5.jpg` → `TJ666-5.jpg`） |
| **② 报价表** | 把报价表里的旧图换成新图，并把货号列的前缀改掉（`.xlsx` 专用，**格式零改动**） |

---

## 给设计部同事：怎么用

### 第一次用
1. 确认电脑装了 **Python 3.9 或更高版本**（[下载](https://www.python.org/downloads/)，安装时**务必勾选 Add Python to PATH**）
2. 双击 **`运行.bat`**
   - 如果提示缺运行库，它会自动联网装一次（`pillow`、`numpy`），之后就不用了
3. 弹出窗口后按下面操作

### 标准流程（贴牌改货号）

**第 ① 步 —— 处理图片**

1. 切到「① 图片文件」页签
2. **输入文件夹** 选要处理的图片目录 → **输出文件夹** 选结果存哪（默认 `输入文件夹\_已处理`，**原图不动**）
3. 处理方式选「**只换前缀**」，填 `JT` → `TJ`
4. 勾上「**同时把文件名里的货号也改名**」
5. 先点「**① 先试跑**」看检测结果 → 没问题再点「**② 开始处理**」
6. 输出目录里就是改好文字、改好名的图；`_对比图\` 里是每张的前后对照，抽查几张

**第 ② 步 —— 处理报价表**

1. 切到「② 报价表」页签
2. **报价表文件** 选 `.xlsx`
   > ⚠️ 老式 `.xls` 要先在 Excel/WPS 里打开 →「另存为」→ 选「Excel 工作簿 (*.xlsx)」。
   > **只把扩展名改成 `.xlsx` 是不行的**，内部结构没变。
3. **新图片文件夹** 选第 ① 步的输出目录（文件名就是新货号）
4. 前缀填 `JT` → `TJ`
5. 先试跑看「逐条对应」列表 → 再正式处理
6. 结果另存为新文件（或勾「覆盖原表」，会自动备份 `.bak`）

处理完打开报价表检查：**列宽、行高、字体、边框、合并单元格、图片位置全部不变**，只有图片和货号列变了。

## ① 图片文件：处理逻辑

对每张图：

1. **定位** —— 在图片底部 86%～99.9% 区域做灰度二值化，按行统计墨量，合并成连续文字行段，
   取**最下面那一段**作为货号行，再取紧贴文字的外框。
   纯几何投影，不用模型，结果完全可复现。
2. **擦除** —— 外框四周各留 24 / 14 像素，填成**背景色**。
   背景色不是写死白色，而是取外框四周一圈像素的中位数，所以浅色渐变底也适用。
3. **重绘** —— 用 **Arial Bold** 渲染新文字，字号按**实测文字高度**反推（先生成高精度字号再整体缩放），
   贴回原来的外框位置。
4. **自检** —— 写完重新读一遍：重绘模式查新文字位置偏差；擦除模式查原文字框内残留墨量。

**为什么用 Arial Bold**：拿真实产品图做过灰度叠加比对，Arial Bold 与原图字体 **IoU = 0.934**，
其它候选差距明显（Arial Black 0.382、微软雅黑 Bold 0.585、Calibri Bold 0.419）。

### 货号从哪来

**从文件名读**：

| 文件名 | 识别出货号 | 写进图片的文字 |
|---|---|---|
| `JT666-5.jpg` | `JT666-5` | `NO.TJ666-5` |
| `JT666-5A-1.jpg` | `JT666-5A-1` | `NO.TJ666-5A-1` |
| `JT888-11Z-1.jpg` | `JT888-11Z-1` | `NO.TJ888-11Z-1` |

规则：`2~4 个字母 + 3 位以上数字 + 可选字母数字后缀`。不符合的用 `--map` 指定。
**所以处理前请先确认文件名就是正确货号。**

## ② 报价表：处理逻辑

`.xlsx` 本质是个 zip。工具只替换其中三个部分，**其它部件一个字节不碰**：

| 部件 | 改什么 |
|---|---|
| `xl/media/*.jpeg` | 换成新图。新图会**缩放到原图同样的像素尺寸**再编码，所以排版完全不变 |
| `xl/drawings/drawing*.xml` | 图片名称/描述里的旧货号改成新货号（`descr` 和 `name` 两种写法都处理） |
| `xl/sharedStrings.xml` | 货号列的文字改掉 |

列宽、行高、字体、边框、对齐、合并单元格、图片锚点都在**没被动过的部件**里，所以一点都不变。

**图片匹配规则**：按货号找同名文件，依次尝试 `旧货号→新货号 映射` → `原名` → `去掉 NO. 再试`。

**写入后自动校验**：zip 完整性、每个 XML 可解析、所有 `.rels` 关系目标存在、
内容类型声明齐全、没有旧前缀残留。任何一项不过就报错，不会给你一个坏文件。

## 命令行用法

### ① 图片

```bat
:: 试跑
python label_tool.py -i D:\图片 -m replace --old JT --new TJ --dry-run

:: 正式：改文字 + 改名 + 对比图 + 报告
python label_tool.py -i D:\图片 -m replace --old JT --new TJ --rename --compare --report 报告.csv

:: 整行擦掉
python label_tool.py -i D:\图片 -m erase

:: 按映射表逐张指定
python label_tool.py -i D:\图片 -m custom --map mapping.json
```

### ② 报价表

```bat
:: 试跑，只看计划
python quote_tool.py -q 报价表.xlsx -d 新图片 --old JT --new TJ --dry-run

:: 输出到新文件
python quote_tool.py -q 报价表.xlsx -d 新图片 --old JT --new TJ -o 报价表_TJ.xlsx

:: 覆盖原表（自动备份 .bak）
python quote_tool.py -q 报价表.xlsx -d 新图片 --old JT --new TJ --inplace
```

### 常用参数

**label_tool.py**

| 参数 | 说明 | 默认 |
|---|---|---|
| `-i` / `-o` | 输入 / 输出文件夹 | 输出默认 `输入/_已处理` |
| `-m` | `replace` / `erase` / `custom` | `replace` |
| `--old` / `--new` | 替换的前缀 | `JT` → `TJ` |
| `--rename` | 同时改文件名/目录名里的前缀 | 关 |
| `--map` / `--text` | custom 模式的映射表 / 固定文字 | — |
| `-r` | 递归子文件夹 | 关 |
| `--dry-run` | 只检测不写文件 | 关 |
| `--compare` | 输出前后对比图 | 关 |
| `--report` | CSV 报告路径 | — |
| `--font` | 指定字体文件 | 自动 Arial Bold |
| `--quality` | JPEG 质量 | 95 |
| `--band-top` / `--band-bottom` | 搜索区上下边界（图高比例） | 0.86 / 0.999 |
| `--ink-thr` | 文字灰度阈值 | 110 |
| `--pad-x` / `--pad-y` | 擦除留白 | 24 / 14 |
| `--tolerant` | 漏检时继续处理其它图 | 关 |

**quote_tool.py**

| 参数 | 说明 | 默认 |
|---|---|---|
| `-q` | 报价表 `.xlsx` | 必填 |
| `-d` | 新图片文件夹 | 必填 |
| `-o` | 输出文件 | `报价表_新.xlsx` |
| `--inplace` | 覆盖原表（自动 `.bak` 备份） | 关 |
| `--old` / `--new` | 前缀 | `JT` → `TJ` |
| `-r` | 图片递归子目录 | 关 |
| `--quality` | 图片重编码质量 | 92 |
| `--dry-run` | 只打印计划 | 关 |

### 映射表格式（custom 模式）

`mapping.json`：

```json
{
  "JT666-5":   "NO.TJ666-5",
  "JT666-5-1": "NO.TJ666-5-1",
  "JT666-5A":  "NO.TJ666-5A"
}
```

键可以是**货号**或**文件名（不含扩展名）**；值可以带 `NO.` 也可以不带（会自动补）。

## 状态符号

| 符号 | 含义 | 怎么处理 |
|---|---|---|
| `✓` | 成功 | — |
| `·` | 试跑（未写文件） | — |
| `!` | 有警告（位置偏差 / 擦除残留） | 看 `_对比图` 里那张，必要时单独处理 |
| `?` | 底部没找到货号文字 | 调 `--band-top`，或那张图确实没有货号 |
| `×` | 出错 | 加 `--verbose` 看完整报错 |

## 注意事项

1. **原文件不动** —— 图片结果写到输出文件夹；报价表默认另存新文件，`--inplace` 会先备份。
2. **.xls 不支持** —— 老式 `.xls` 是 OLE2 二进制，图片存在 BIFF 流里，改一处就会让 Office 报文件损坏。
   而且 `.xls` 内部本身含一个小 zip，**只改扩展名会被误判成 xlsx**；
   工具会检测工作表是否存在并给出明确提示。
3. **文件名必须是正确货号** —— 两个工具都靠文件名对应。
4. **搜索区可调** —— 货号不在底部就调 `--band-top`；下方有其它文字干扰就收窄 `--band-bottom`。
5. **JPEG 重编码** —— 图片默认 `--quality 95`；报价表里的图默认 92。
   原图若已多次压缩，可调高以减少损失（代价是文件变大）。
6. **中文货号** —— 当前字体链只有拉丁字形，中文会显示成方块，需用 `--font` 指定中文字体。
